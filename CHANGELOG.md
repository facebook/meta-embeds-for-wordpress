# Changelog

All notable changes to this project will be documented in this file.

## 1.0.0

* Initial release.
* Threads oEmbed provider registration for `threads.com` and `threads.net` URLs.
* Block Editor embed variation with dedicated Threads icon.
* Automatic embed.js SDK loading with deferred strategy.
* Core deduplication — skips registration when WordPress already provides a Threads endpoint.
